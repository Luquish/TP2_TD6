# Online Ad Click Prediction with Machine Learning 🚀📊

## Overview
This project aims to develop a predictive system that determines whether a user will click on an online advertisement. The main challenge was not only selecting and tuning the predictive model but also ensuring thorough data cleaning and effective feature engineering. Our final model was selected based on its superior ROC-AUC performance.

## Project Structure and Key Components
The project is organized into several key sections:

### 1. Data Exploration and Cleaning
- **Data Concatenation:**  
  Multiple training datasets were combined (excluding the test set) to build a more robust and representative dataset. We used an `augment_data_train` function to append rows from additional datasets, focusing on rare or unknown categories.
- **Data Integrity Checks:**  
  We verified the total number of rows post-concatenation and compared the dimensions with the individual datasets to ensure correctness.
- **Missing Values Analysis:**  
  We performed a detailed analysis of missing values across all columns, particularly noting that many categorical variables had a significant number of missing values. This insight influenced our later decisions regarding one-hot encoding.

### 2. Exploratory Data Analysis and Feature Engineering
- **Variable Analysis:**  
  We distinguished between categorical and numerical features, analyzing the distribution of the target variable (click vs. no-click) and the correlation between variables and the target.
- **Visualizations:**  
  - Distribution of the target variable (click rates).  
  - Bar graphs and correlation plots (see Figure 1 and Figure 2) to highlight significant patterns.
- **Feature Engineering:**  
  Several new attributes were created to enhance the model’s predictive power:
  - **Binary Features:** Derived from list-type columns (e.g., auction list, action list) using a custom function (`expand_list_dummies_cython`).
  - **Time-Based Features:** Created features such as weekday and moment of the day (early, afternoon, night) based on the auction time and timezone offset.
  - **Composite Features:**  
    - `level_combination`: Generated by concatenating parts of multiple categorical columns.  
    - `hxw`: The product of creative height and creative width.
  - **Encoding:**  
    - Gender was numerically encoded (e.g., ‘f’ as 1, ‘m’ as 2, ‘o’ as 0, NaN as -1).
    - Redundant categorical columns were removed after analysis showed they did not add value.

### 3. Validation Set Construction
- **Initial Split:**  
  We initially set aside 20% of the training data as a validation set using stratified splitting to preserve the distribution of the target variable.
- **Cross-Validation:**  
  To mitigate overfitting (observed when optimizing solely on a fixed validation set), we implemented 3-fold cross-validation. This approach provided a more stable and generalizable performance estimate.
- **Alternate Approach:**  
  We also explored (but did not implement) using a k-nearest neighbors algorithm to replicate the test set’s characteristics, aiming to better anticipate production performance.

### 4. Predictive Modeling
- **Model Experimentation:**  
  Several models were evaluated:
  - **Decision Trees:** Selected initially for their simplicity and ability to handle mixed data types.
  - **Random Forest:** Implemented with target encoding to improve robustness.
  - **Boosting Methods:** We tested multiple boosting approaches and finally selected XGBoost.
- **Hyperparameter Tuning:**  
  Hyperopt was used to optimize key parameters (tree depth, learning rate, number of estimators, regularization techniques, etc.) with cross-validation to find the best performing model.
- **Final Model:**  
  XGBoost, using one-hot encoding for categorical variables, achieved the highest ROC-AUC and was chosen as our final predictive model.

### 5. Analysis of Feature Importance
- An in-depth analysis of feature importance was conducted using the final XGBoost model.
- The top 20 features influencing the predictions were identified (see Figure 4), providing valuable insights for potential dimensionality reduction and future model improvements.

### 6. Conclusion
- The project successfully built a predictive model to estimate the probability of an online ad click.
- The key to achieving a high-performing model was a thorough data cleaning process, effective feature engineering, and rigorous hyperparameter tuning.
- Our final solution, based on XGBoost optimized with Hyperopt and validated through cross-validation, demonstrated the best ROC-AUC performance compared to other evaluated methods.
